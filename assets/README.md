# Pink Mall hero asset

## `pinkmall-sisters-hero.webp` — ЛИПСВА, трябва да се добави тук

Слайд 02 на Hero билборда (`#pinkMallSlide` в `PINKMALL.html`) очаква този файл.
Докато го няма, JS слага `.pm-image-missing` на слайда:
`<img>`-ът се скрива, отдолу остава дизайнерският Y2K градиент, а
**hotspot-ите и sister label-ите също се скриват** — продуктови точки върху
празен градиент нямат смисъл. Страницата не се чупи.

Конвертирай от оригинала без промяна на crop, цветове или ретуш.

### Изисквания

| | |
|---|---|
| Име | `pinkmall-sisters-hero.webp` (WebP, качество ~85–90) |
| Размер | **1086 × 1448 px** (portrait, 3:4) |
| Съдържание | двете сестри, топъл pink/orange studio фон с диагонални neon lights |

### Ако размерът се промени

Координатите на hotspot-ите се смятат в **image-space** (% от оригинала).
При друг размер обнови двете константи в скрипта
`PINK MALL — IMAGE-SPACE ANCHOR LAYOUT` в `PINKMALL.html`:

```js
var PM_IMG_W = 1086;
var PM_IMG_H = 1448;
```

Ако кадърът е различен (други пози/позиции на продуктите), обнови
`data-pm-ix` / `data-pm-iy` на четирите `.pinkmall-hotspot` бутона —
това са процентни координати спрямо самата снимка, не спрямо екрана.
